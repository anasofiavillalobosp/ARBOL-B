## Descripción

Este proyecto implementa la estructura de datos **Árbol B**, permitiendo trabajar con sus operaciones principales y comprender su funcionamiento mediante la organización de claves en páginas y la reestructuración del árbol.

## OPERACIONES
| N.º | Operación | Descripción |
|---|---|---|
| 1 | Insertar clave | Agrega una nueva clave al árbol B, manteniendo sus propiedades de orden y balance. |
| 2 | Buscar clave | Comprueba si una clave determinada existe en el árbol. |
| 3 | Eliminar clave | Elimina una clave del árbol y reorganiza sus páginas si es necesario. |
| 4 | Consultar mínimo | Devuelve la clave de menor valor almacenada en el árbol. |
| 5 | Consultar máximo | Devuelve la clave de mayor valor almacenada en el árbol. |
| 6 | Buscar rango | Obtiene las claves que se encuentran dentro de un intervalo determinado. |
| 7 | Recorrer en orden | Muestra las claves del árbol en orden ascendente. |
| 8 | Mostrar árbol por niveles | Imprime la estructura del árbol B nivel por nivel. |
| 9 | Consultar altura | Devuelve la altura del árbol, es decir, la cantidad de niveles que contiene. |
| 10 | Consultar si está vacío | Comprueba si el árbol contiene claves o se encuentra vacío. |
| 11 | Dividir y reestructurar | Permite observar la división de páginas y la reorganización que ocurre cuando se producen desbordamientos durante la inserción. |
| 12 | Limpiar árbol | Elimina todos los elementos y deja el árbol con una nueva raíz vacía. |
